### 📦 Quick Install

- **macOS / Linux**:
  ```bash
  curl -fsSL https://get.yamlr.dev/install.sh | bash
  ```
- **Homebrew**:
  ```bash
  brew install yamlr/tap/yamlr
  ```
- **Windows**:
  Download `yamlr-windows-x86_64.zip` from [Releases](https://github.com/yamlr/yamlr/releases/latest).
